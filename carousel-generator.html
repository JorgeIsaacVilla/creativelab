Crea un carrusel completo en pocos pasos

Añade hasta 24 piezas de contenido, carga tu identidad visual y deja que el generador combine layouts, imágenes, gradientes y elementos decorativos respetando zonas seguras.

El modo Código utiliza el formato ALFORA-CAROUSEL/1 para que puedas preparar el contenido con una IA, pegarlo en la herramienta y convertirlo rápidamente en un carrusel visual.

Cómo funciona el código de Alfora

ALFORA-CAROUSEL/1 es un formato de texto simple. Cada pieza se identifica con c1, c2, c3 y así sucesivamente hasta c24. Cada pieza puede contener title, copy e imagen.

ALFORA-CAROUSEL/1
c1.title: "Convierte ideas en contenido"
c1.copy: "Crea una pieza visual clara y atractiva."
c1.imagen: "auto"

c2.title: "Diseña más rápido"
c2.copy: "Alfora organiza el contenido automáticamente."
c2.imagen: "2"

En imagen puedes escribir "auto" para que Alfora seleccione una imagen cargada automáticamente, o indicar su número, por ejemplo "2".

También puedes pedir el código a una IA

Una IA puede crear el contenido completo y devolverlo listo para pegar. Solo debe respetar ALFORA-CAROUSEL/1, usar una línea por campo y numerar las piezas desde c1.

Ejemplo de instrucción para una IA: “Genera un carrusel de 6 imágenes sobre mi producto en formato ALFORA-CAROUSEL/1. Para cada imagen escribe cN.title, cN.copy y cN.imagen entre comillas. Usa imagen: "auto" y no añadas explicaciones fuera del código.”
