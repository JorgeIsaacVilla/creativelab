Separación inteligente y gratuita

Separa automáticamente objetos y elementos de una imagen o rodea una pieza con el pincel inteligente para aislarla como una capa transparente. Todo se procesa directamente en tu navegador.

Separación automática y asistida

Usa la separación completa cuando quieras detectar varias piezas de una vez, o activa el pincel para indicar con precisión qué objeto deseas convertir en una capa independiente.

Capas listas para reutilizar

Mueve, oculta, aísla y descarga los elementos detectados como PNG transparentes. La escena restante se mantiene para que puedas continuar separando más piezas.

Procesamiento local

Los motores principales trabajan en tu dispositivo mediante WebGPU o WASM, manteniendo el flujo de trabajo dentro del navegador siempre que el equipo sea compatible.

Nota de integración: esta es todavía la versión de trabajo. Conserva toda la lógica funcional de V5.2, pero ya utiliza la jerarquía visual, colores, superficies, bordes y estructura de producto de Alfora. En la migración final se conectará completamente a language.js, shared.js y a los JSON actualizados de element-separator.
