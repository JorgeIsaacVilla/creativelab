Selección simple y transparente

Cómo separar un elemento con Alfora

La herramienta permite seleccionar por puntos o trazo libre, corregir el contorno y exportar tanto el elemento aislado como la imagen original con el área recortada transparente.

1. Carga

Selecciona una imagen PNG, JPG o WebP.

2. Delimita

Marca puntos o dibuja el contorno y corrige cualquier punto antes de aislar.

3. Descarga

Descarga el elemento aislado o la imagen completa con el hueco transparente.
